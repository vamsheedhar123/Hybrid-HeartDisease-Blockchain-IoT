# A Hybrid Framework for Heart Disease Prediction and Blockchain-Based Healthcare Data Management with Secure IoT Communication

This repository contains the official implementation of the paper **"A Hybrid Framework for Heart Disease Prediction and Blockchain-Based Healthcare Data Management with Secure IoT Communication"**.

The framework combines an **Improved Capsule Squeeze-Excited (SE) Scalable Residual Triangulation Long Short-Term Memory (ISRT-LSTM)** model for accurate heart disease prediction with a **Blockchain-based Quantum Hash Newton-Raphson Attribute-Based Encryption (QHNABE)** mechanism for secure healthcare data management.

---

## 📌 Features & Architecture

* **Preprocessing:** Dynamic Gaussian Piecewise Normalization (DGPN) for multi-source clinical data handling.
* **Predictive Model:** ISRT-LSTM combining capsule-based feature representations with residual learning.
* **Security & Access Control:** QHNABE mechanism for secure data storage and management over Blockchain.
* **Optimization:** Triangular exploration and Newton-Raphson optimization for hyperparameter tuning.
